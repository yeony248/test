# 배경음악 폴더

여기에 mp3 / m4a / wav 파일을 넣으면 상품마다 **돌아가며 자동 배정**됩니다.
파일이 하나도 없으면 무음으로 렌더됩니다 (에러는 아닙니다).

- **5개 이상** 넣으세요. 하나만 넣으면 전체 영상이 같은 음악이 되어 중복 콘텐츠로 잡히기 쉽습니다.
- 곡의 시작 지점도 상품마다 다르게 잘라 쓰기 때문에, 1분 이상 길이의 음원이 좋습니다.
- **상업적 이용이 허용된 음원만** 쓰세요. 유튜브 오디오 보관함, 구매한 라이선스 음원 등.
- 음량은 `bulkvid/config.py`의 `RenderSettings.bgm_volume`(기본 0.28)에서 조절합니다.

이 폴더의 음원 파일은 `.gitignore`로 제외되어 커밋되지 않습니다.
